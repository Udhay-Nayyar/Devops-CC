Kubernetes Architecture ?

Master Node             
API server -  communication channel between the master and worker   
controller manage -  manages things at the master side
scheduler  - this will schedule the formation of the container              
etcd - act as the database on the master side




Worker side 
Pods - it is like a unit where grp of container runs togther 
Server Proxy - some one from out side the organisation want to access the conatiner services will take help from this server proxy 
Kubelet - acts as the manager on the worker side

How do these node communicate with each other 
using the CNI network

Solution Namespace



> kubectl get ns 
> kubectl get namespace
------------------------ read how many name space we have

Note we also have a default name space called as default 

> kubectl get pods
------------------------ ready kro bhai kitna pods are running right now 
                         this will go search for the pods in the default namespace 
but if you want to check the pods in the particular namespace then the commands become
> kubectl get pods -n "name of the namespace"


how do we create a name space ?
> kubectl create ns "name of the namespace"



now in the namespace you have just created we will create the pods , deployment , services in this namespace 
so lets goo



> kubctl run nginx --image=nginx
-------------------------------- This commads helps us to create the pods for the nginx 
their is a catch here that this will create a pod no doubt but this will add the pods in the default name space
so in order to avoid that we will use the command that is written below 

> kubctl run nginx --image=nginx -n nginx
                                    -----
> kubectl delete pod nginx  



now try to locate the nginx pod in the nginx namespace 
using command
> kubectl get pods -n nginx
