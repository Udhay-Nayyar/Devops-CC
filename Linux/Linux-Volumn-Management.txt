what is the diff between 
physical volumn and logical volumn in linux 

1.  A physical volume is an actual storage device that Linux/LVM can use
2. A logical volume is a virtual disk created from a Physical Volume through LVM

what was the process ?  
create a ebs ---> physical volumn ---> volumn grp ---> logical volumn 


sudo pvcreate /dev/nvme1n1 /dev/nvme2n1 /dev/nvme3n1   ---->  creating the physical volumn 
sudo vgcreate tws_vg /dev/nvme1n1 /dev/nvme2n1 /dev/nvme3n1  ----> creating the volumn grp 
sudo lvcreate -L 10G -n tws_ls tws_vg >>> this will create the logical volumn
