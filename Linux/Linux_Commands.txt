Permission commands 
How do linux use the permission system ? 
it uses R (read) , W (write) , X (execution)
ls -l -> detailed description about the files and folders present in that directory 
chmod XXX name_of_the_directory (must know what is behind the XXX logically)
chown -> change the owner of the any directory 
chgrp -> change the grp that the directory belongs to 
sudo chown udhay file.txt
unmask -> This help us to set few default permission that will be give to any directory created in the future 

Remember 
umask → controls default permissions
chmod → changes permissions of existing files
chown → changes ownership



Zip and Compression commands
step 1  - Let us first zip a folder 
          

| Feature      | `.zip`                      | `.tar`                          | `.tar.gz`                           |
| ------------ | --------------------------- | ------------------------------- | ----------------------------------- |
| Main tool    | `zip` / `unzip`             | `tar`                           | `tar`                               |
| What it does | **Archive + compress**      | **Archive only**                | **Archive + compress**              |
| Compression  | ✅ Yes                     | ❌ No                           | ✅ Yes (`gzip`)                      |
| Example file | `files.zip`                 | `files.tar`                     | `files.tar.gz`                      |
| Create       | `zip files.zip file1 file2` | `tar -cf files.tar file1 file2` | `tar -czf files.tar.gz file1 file2` |
| Extract      | `unzip files.zip`           | `tar -xf files.tar`             | `tar -xzf files.tar.gz`             |
| `c` means    | —                           | **create**                      | **create**                          |
| `x` means    | —                           | **extract**                     | **extract**                         |
| `f` means    | —                           | **file**                        | **file**                            |
| `z` means    | —                           | —                               | **gzip**                            |
